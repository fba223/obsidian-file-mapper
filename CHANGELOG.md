# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-02-20

### Added

- Multi-source directory mapping (multiple paths support)
- Customizable YAML frontmatter field names
- Auto-sync with configurable duration
- Customizable date format (YYYY-MM-DD, DD/MM/YYYY, etc.)
- Optional time inclusion in date fields
- File size unit selection (Bytes, KB, MB, GB)
- Manual sync button
- Clickable file links to open original files
- Comprehensive README documentation

### Features

- Scan multiple source directories simultaneously
- Recursive directory scanning
- Detect new, modified, and deleted files
- Periodic automatic synchronization
- Flexible date/time formatting
- Configurable file size display units

## [0.0.1] - 2024-01-01

### Added

- Initial release
- Basic file mapping from single source directory
- Default YAML frontmatter
- Basic sync functionality
